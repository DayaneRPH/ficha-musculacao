# Ficha de musculação

Aplicativo web de acompanhamento de treinos desenvolvido para facilitar a organização e o monitoramento de exercícios durante a rotina de musculação.

## Sobre o projeto

O produto foi desenvolvido com o objetivo de tornar o acompanhamento dos treinos mais prático, intuitivo e organizado, permitindo visualizar os exercícios de cada ficha e monitorar o progresso durante a execução.

A proposta é oferecer uma experiência simples, funcional e acessível, sem a necessidade de utilizar aplicativos complexos para acompanhar as séries de treino.

## Funcionalidades

- Organização de treinos em fichas independentes (A, B, C e D).
- Acompanhamento individual das séries por exercício.
- Marcação de séries concluídas.
- Indicador visual de progresso do treino.
- Salvamento automático do progresso.
- Possibilidade de reverter marcações.
- Feedback visual ao concluir o treino.

## IA utilizada

- ChatGPT

## Linguagens utilizadas

- HTML5
- CSS3
- JavaScript

## Acesso

Aplicação disponível online pelo GitHub Pages.

## Objetivo

Desenvolver uma ferramenta funcional, intuitiva e centrada na experiência de uso, facilitando o acompanhamento dos treinos e incentivando a consistência na rotina de exercícios.
